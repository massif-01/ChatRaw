# 发布验收矩阵

状态值：not_started / simulated_pass / real_pass / blocked / failed。必须附提交号、命令/步骤、环境/版本和证据；不以数量代替语义。

|ID|范围|通过标准|Owner|
|---|---|---|---|
|G01|插件|五插件安装/启用/配置/检查/禁用/卸载；同一聊天单选；刷新不丢绑定|B/F|

|G03|上下文|Agent outbound无ChatRaw历史/摘要/system/skills/RAG；普通聊天保留|A/B/F|

每个Agent独立记录：版本、probe层级、认证方式、文本、工具、问答、审批允许/拒绝、停止、恢复、压缩、附件、不支持项。
能力原生不提供时可按如实声明/清晰提示验收，不能为了通过而伪造交互或强制绕过权限。Chrome109和五种真实接入属于交付门槛，缺失时不得宣告全部完成。

视觉验收通过既有小预览不是正式动态Markdown验收；浏览器尺寸模拟不是移动软键盘/系统重启实测。分别列证据。
问题优先级：P0权限/数据/错误执行；P1核心功能/恢复/兼容不可用；P2不影响核心交付的细节。P0/P1必须闭环，P2有界处理，避免无期限循环。
