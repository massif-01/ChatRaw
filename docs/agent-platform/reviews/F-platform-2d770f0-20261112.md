证据位置（固定快照）：

- `agent_runner/validation.py:163–184`：这是允许的 multi + allow_custom 回复；Runner 接受它。

4. 删除自定义文本后重试，同 interaction 返回 **409 reply_conflict**，只能停止本轮，无法完成原问答。
